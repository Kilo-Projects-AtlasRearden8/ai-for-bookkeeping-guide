# AI for Small-Business Bookkeeping

A plain-English beginner manual on using AI for small-business bookkeeping:
categorizing expenses, tracking income, receipts, quarterly tax prep, and
knowing when to hire a pro. Includes printable worksheets.

**Education only. Not tax advice.** See the disclaimer in `docs/00-read-me-first.md`
before you use anything in this guide.

## Who this is for

This guide was written by **Asdale Dynamics, LLC** (Indiana, formed October
2026), the LLC behind Dylan Asdale's book *The Massive AI Manual* and hub site
dylanasdale.github.io. It is for small-business owners, freelancers, authors,
and side-hustlers who want to use AI to stay on top of their books without
becoming accountants. No prior bookkeeping or AI experience required.

## What's inside

- `docs/` — the full manual in Markdown (print-friendly)
- `site/` — the same manual as a static HTML site you can open in any browser
- Worksheets in both `docs/worksheets/` and `site/worksheets/` for printing

## How to run it

The site is plain HTML, CSS, and JavaScript. No build step, no server, no
installation:

1. Open `site/index.html` in your web browser.
2. Click through the chapters in the navigation.
3. Open any worksheet page and press `Ctrl+P` (or `Cmd+P`) to print it.

Or read the Markdown files in `docs/` directly.
